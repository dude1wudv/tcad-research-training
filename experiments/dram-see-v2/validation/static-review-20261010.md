# v2 静态审阅：预充、恢复与统计契约

日期：2026-10-10。范围：`build_case.py`、`audit.py`、`event_audit.py`、`transport.py`、`statistics.py`、`plan.md`。本记录只证明代码审阅；未启动仿真、连接 VM、执行数据验收或修改业务代码/deck。父代理报告的失败 pilot 未由本 worker 检查原始归档，不能视为独立复核。模型请求为 gpt-6-astra medium；本 worker 未取得独立运行时模型/推理等级/OAuth 路由证明。

## 优先问题

1. **高：冻结输入与分析依据未完全绑定。** `audit.py:28` 核对 inputs.tar 内文件与 manifest，但随后 `:35` 从 results.tar 读取 parameters.json，没有校验两份参数逐字节相同。分类阈值、存储位、父运行和源元数据由结果侧参数决定。应首先绑定结果内参数、deck、restart-provenance 与冻结输入（对运行中合法变化的输出另列名单）。源文件目前有专项哈希核对，是已有优点；仍应拒绝正 Q 却没有源证据的运行。

2. **高：同时间重复样点静默选择，可能丢失状态切换。** `audit.py:10,40,47` 在保持段保留 first，在全程/读出段保留 last；没有检查同时间电压是否一致、是否为允许的边界。尤其 3 ns 的 `before[0]` 用作理想共享参考，而积分使用 `sharing[0]` 的最后样点，若两者 SN/BL/REF 不同，释放时的非物理跳变可以从积分窗口消失。应保留原始顺序，显式标记各阶段左右极限；对 Unset 的 SN/BL/REF 电压连续性断言；非切换边界的冲突重复样点报错。BE 积分每个真实时间区间使用其收敛终点电流，不用跨切换合成曲线。2.8 ns 保持末点应明确为预充前值，而不能仅依赖输出顺序。

3. **高：直接 Set 预充尚需验证。** `build_case.py:84` 将 BL 从 0 瞬间钳位到 0.5 V；100 fF 理想电容的充电量为 50 fC，零上升时间对应未解析的理想冲击。删除其后的静态 Coupled 可避免对浮置 SN 做不适当 DC 重平衡，但不能自动证明这一瞬时预充的瞬态实现可靠。优先采用有限斜率的电路驱动并在 3 ns 断开；若保留理想 Set，应明确理想化边界，记录切换前后 SN、BL 电荷/电压，检查预充期间 SN 耦合和时间步敏感性。预充阶段不能从所有守恒检查中消失：至少验证未钳位 SN 的 KCL/电荷平衡。钳位 BL 的守恒则必须包含外部预充源电流，不能用当前只含 access/cbl/rbl 的方程检查。

4. **中高：独立事件与对照资格目前是调用方责任。** `statistics.py:12` 只接收类别列表并将长度命名为独立事件数；本模块不能拒绝同事件重跑、0/1 成对重复、混合条件、不同模型版本或无粒子对照不合格。汇总入口必须先按固定条件和存储位分层，核验唯一事件身份、冻结种子清单、成功审计和正确的匹配对照，再调用函数。不能将两个存储位配对结果合并为两次独立入射。失败运行应单列，不能通过只取成功子集而默认为完整预定样本。

5. **中：恢复需要实测等价性及更完整兼容检查。** `build_case.py` 已拒绝跨栅长/网格/存储位恢复，是正确边界。但兼容键未覆盖存储电容、参考电容、预充电压、初始化/时序、物理模型及电路版本。`audit.py` 核对了所列复制文件哈希，却未重算父 results.tar 的完整哈希，也未要求复制清单恰好包含 mesh、device save、circuit save 三个文件。建议绑定完整初始化配置摘要，检查父归档实际摘要，并对同条件完整运行与恢复运行比较 0.95 ns 的 SN/BL/REF/WL 和后续 D；仅二者分别落入目标 ±1 mV 不足以证明同初态。Load 后应通过证据确认 SN 保持释放状态，避免误继承钳位。

6. **中：元数据声明仍有缺口。** `event_audit.py` 未核验 conversion_eV_per_pair==3.6、schema、converted[0].event==0、固定栅长集合和 launch_position；计算使用 3.6，因此错误声明可能通过。`transport.py:28` 的 source_sha256 是当前本地源文件摘要，单独不能证明远端已安装 binary 由它编译；应引用 v1 的已归档构建来源绑定，或准确称为本地参考源码摘要。

7. **低：阈值与电容硬编码。** `audit.py:102` decoded_bit 固定使用 5 mV，而 classification 使用参数阈值；积分、理想共享与 raw_hold_loss 也硬编码电容。当前固定参数时一致，但建议从已验证冻结参数读取，防止后续变更导致自相矛盾。共享段最好显式要求首点恰为 3 ns，并验证释放至 WL 上升前的偏置与参考节点稳定性。

## 建议的最小定向复验

- 预充流程修正后的单个高位无粒子完整运行：检查 2.8 ns 前后、3 ns 释放前后、3.05/3.10 ns WL 边界的原始重复样点和各阶段守恒；随后覆盖低位。
- 同几何/同位的完整与恢复运行比较，确认状态连续及差分读出一致。
- 四栅长 × 两位无粒子基准均通过，才支持四栅长统一初态与基准可读性结论。
- 固定输入的最接近读出边界粒子点及匹配对照做时间步减半；按计划 0.5 mV 目标检查。边界应考虑分类阈值 ±5 mV，而不仅 D=0。
- 统计阶段单独验证种子清单、事件唯一性、每位分母和完整样本数；报告 Geant4 沉积统计与 TCAD 误读统计的不同证据范围。

Wilson 与零事件单侧上界公式在静态审阅中未发现代数问题；未运行数值测试。以上不构成三项目标验收，仍需实际求解、归档和冻结后的定向检查。
