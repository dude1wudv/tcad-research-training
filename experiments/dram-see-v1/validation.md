## 独立审查发现与处理

1. 验证代理最初将梯形电流积分差异套用到后向欧拉的离散守恒门槛，产生一个失败断言。核对 deck 与离散方程后确认前提错误，代理撤回该判断并修正测试。初次失败和解释仍在原始审查记录中；分析中的梯形结果没有删除，保留为时间步敏感性观察量。
2. 代理发现真实追溯缺口：已有事件只验证 CSV 自报哈希，没有与矩阵条件逐项绑定，也未冻结事件 JSON 到 TCAD 输入。主 Agent 修正，代理定向测试通过。新粒子输入包含源 JSON/CSV，参数和 runner manifest 同时固定哈希，分析从归档验证；旧 pilot/首个续算保留真实的 legacy 标记。
3. 汇总进一步对照当前事件文件和归档证据哈希，防止同条件/同 Q 的来源替换；不得仅根据可修改的 summary 绘图。原始输入、失败 manifest 和原始求解归档未回写；派生 CSV/JSON 可按当前分析器重新生成。
4. 模型在 2026-10-09 18:23:58 UTC、域外粒子响应数为 0 时冻结系数。后续汇总核对训练 run IDs、矩阵哈希和系数，防止静默重拟合；数据分组和四特征模型未改变。

独立审查的完整脱敏记录位于 `local_runtime/dram-see-v1/validation/`：`geant4-environment-validation.md`、`tcad-pipeline-review.md`、`tcad-binding-review.md`。实际命令与退出码见这些文件及工具运行记录。
