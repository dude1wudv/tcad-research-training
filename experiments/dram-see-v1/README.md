采用自编二维平面 NMOS + 10 fF 理想电容的 1T1C 单元；栅长 0.18/0.25/0.35/0.45 µm、5 MeV alpha/proton、0°/30°，每条件一个固定种子事件。无实验室 DRAM 工程和器件校准，不是商业工艺节点模型，不报告位翻转率或截面。旧 PN/VDMOS 数据没有混入结果。

限定中文模板驱动参数矩阵，Geant4 真实电离沉积换算为等效均匀 HeavyIon 径迹；冻结回归仅用 8 个训练工况，另有 4 点域内留出和 4 点域外验证。它是依赖 Geant4 Q 的两阶段代理模型，不是通用 LLM 参数理解或已校准的端到端物理预测器。

完整输入/命令/stdout/stderr、工具下载和原始运行归档保留于 `local_runtime/dram-see-v1/`、`local_runtime/runs/`；TCAD 唯一执行入口仍是 `scripts/tcad.py`。本目录保存可审阅的小型 CSV/JSON、源代码、图件、哈希和报告，不包含连接秘密、许可证或受限商业资料。当前会话未取得仓库历史指定模型配置的运行证明，不冒称指定模型科研验收；没有提交或推送 Git。
