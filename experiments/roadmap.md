## 3. 最小闭环与接口草案

拟数据流：自然语言请求 → 结构化工况与约束检查 → 冻结输入 → Geant4 事件 → 传递数据与检查 → TCAD 瞬态求解 → 指标提取 → 图表和证据索引。以下为课程接口要求；v1 的已实现字段和验证边界以其 workflow.md、event_contract.py 和 validation.md 为准。

### 3.1 模型与无辐照基线

优先接收实验室 DRAM 模型及参考运行，明确是器件、存储单元还是带电路的模型。记录几何尺寸实际指什么、维度、材料、接触、掺杂、工作状态和参考依据；确认模型可支持哪一种单粒子效应观察量。不能仅把某个晶体管缩放后称为不同工艺节点，也不能用 SRAM 或 PN 结构代替大纲中的 DRAM 范围。

多尺寸比较采用教师认可的参数集合。每组尺寸应给出结构/工艺来源和随尺寸共同变化的参数；若采用理想化几何缩放，明确它仅为受控简化模型。先通过无辐照初始状态与基础电学检查，再引入粒子事件。

### 3.2 Geant4 到 TCAD 的数据约定

| 拟记录内容 | 必须说明的含义 | 接口验收方式 |
|---|---|---|
| 来源标识 | schema 版本、输入哈希、事件 ID、随机种子、工具/模型配置、父子 run ID | 同一条结果能追溯到两端输入与原始事件；不承诺跨版本逐位重现 |
| 结构与坐标 | 长度单位、原点、轴向、材料/区域 ID、敏感区域、坐标变换及维度 | 用已知位置样例检查映射、边界与区域归属 |
| 粒子条件 | 种类、能量及单位、入射位置、方向向量或角度约定、时间 | 明确角度零点和方位定义；转换前后条件一致 |
| 事件沉积 | 每个记录的空间范围、时间、沉积量/单位、权重与保留/丢弃原因 | 明确记录粒度和积分范围；分别汇总区域内外数据，不静默丢失 |
| TCAD 激励 | 从沉积量到载流子源项的转换依据、材料参数、空间/时间分配与单位 | 在同一物理体积和时间窗口核算输入与转换后积分；容差预先定义 |
| 离散化与误差 | 重采样、平滑、截断、网格及时间采样设置 | 比较转换分辨率变化，并量化对最终观察量的影响 |

选择直接空间源项、等效径迹或其他注入方式，需要依据所用 Sentaurus 版本的合法文档、模型能力和对照验证，课程方案不预先限定语法；v1 已选择等效均匀 HeavyIon 径迹并记录信息损失。若将三维事件投影到二维模型，必须先定义有效厚度、归一化与信息损失，并说明能回答和不能回答的问题；不能仅删除一个坐标。转换输入积分与输出积分的核对不等于整个电学过程已经完成物理守恒验证。

接口先用可解析的人工样例检查坐标、单位、边界和积分，明确标注“接口测试数据”；随后必须使用真实 Geant4 事件验证实际传递、TCAD 载入与响应。人工样例不能作为辐射效应结果。

### 3.3 单粒子效应输出与判据

候选观察量包括端电流瞬态、收集电荷、存储节点电压变化及教师认可的失效判据。它们是待选指标，不是已定义结果。每项需明确接触/节点、参考状态、符号、单位、时间窗口与提取方法；电荷积分须说明是否扣除无辐照基线、观察窗口是否足够、二维归一化怎样处理。

只有模型包含所需存储状态、读取条件和判据时，才讨论位翻转；只有事件统计、入射采样和归一化已定义时，才报告截面或概率。最小闭环的一个事件只证明链路可运行，不能代表全部粒子条件或统计分布。

### 3.4 自然语言改参与遍历

自然语言先转成可审阅的参数表：目标模型、参数名、原值/新值、单位、扫描列表、固定条件、来源、预计工况数及预算。检查允许字段、范围、单位、耦合约束、重复工况和预算后生成两端输入差异；已批准范围内按既有授权执行，超出范围停止并给出原因。AI 不直接生成任意 shell 命令来执行用户文字。

演示样例可为“对已批准的尺寸集合和入射方向生成扫描”；实际数值由冻结表提供，歧义请求需澄清。保留一个有效请求和一个越界/歧义请求的处理证据，并核对生成参数与真实 deck/事件配置一致。复用现有 `scripts/tcad.py` 的 TCAD 执行和归档能力；v1 在专用实验目录实现 Geant4 适配、输入生成和接口检查，TCAD 仍复用该 runner。

## 4. 扫描与预测验证

先围绕一个已通过的基准做小规模单因素检查，再根据实际成本设计多参数覆盖。工况表至少含尺寸/结构版本、工艺参数、粒子种类/能量、位置/方向、存储状态、温度/偏压、事件种子/数量、固定条件和输出定义。参数范围、事件重复数和误差目标不由 AI 凭空设定。

拟合流程按以下顺序冻结：

1. 定义输入特征、预测目标和有效数据规则；保留失败索引，防止只展示成功点。
2. 按物理工况或尺寸组划分训练、调参验证、最终测试数据。同一工况的重复事件不跨集合泄漏；预处理参数只由训练数据确定。
3. 先建立简单、可解释的基准拟合，再按数据量选择 AI/机器学习方法，记录版本、超参数和种子。大模型参与操作不等于已完成效应预测。
4. 域内留出测试评价插值能力；另行明确训练覆盖域，预留域外尺寸或粒子条件评价外推，避免把随机留出自动称为外推。
5. 以未参与训练/调参的真实联合仿真核对域外预测；有独立实验或文献参考时另列比较。仿真对仿真验证仅检验代理模型对该仿真体系的近似，不能称为实验校准。
6. 报告预先选定的绝对误差指标、必要的相对误差处理、关键/最差工况误差及失败区域；若目标是分类，另定类别与评价口径。指标与阈值在查看最终测试结果前固定。

没有域外验证数据时，R7 尚未完成，外推输出只能标作未验证预测。预算不足时先减少可选效率对照与扫描规模，再与教师讨论范围调整，不能悄悄删除大纲要求的 Geant4、自然语言改参或预测验证。

## 5. 阶段安排与分工草案

以下为约 8 周的排程草案，起点是模型/资源具备且方案获认可之时，非教师规定工期。资源交接未完成的等待不计作阶段通过；实际日历、负责人和机时按截止时间与试运行结果填写。

| 建议窗口 | 阶段及依赖 | 产物与完成条件 |
|---|---|---|
| 第 1 周 | G0–G1 资源、来源与方案 | 交接清单、参数来源、可行性更新、范围与进度获审核；接口初稿 |
| 第 2 周 | G2 两端基础模型 | Geant4 最小例程、DRAM 无辐照真实基线、尺寸定义与输出口径 |
| 第 3–4 周 | G3 最小联合闭环 | 单事件转换/TCAD 瞬态；接口、网格/时间步检查；自然语言改参案例；测得运行成本 |
| 第 5 周 | G4–G5 冻结并执行核心扫描 | 冻结矩阵、数据划分、预算和停止条件；不同尺寸、粒子与方向的真实数据 |
| 第 6 周 | G5–G6 拟合与独立验证 | 基准与预测模型、域内/域外验证、误差和适用范围；不足时补必要工况 |
| 第 7–8 周 | G7 报告与演示 | 完整报告、证据索引、试讲反馈、可复现演示与交付备份 |

建议按职责分工：一人负责 DRAM/TCAD 与数值检查，一人负责 Geant4/传递与接口检查；若有第三人负责数据/预测和集成。两人组共同承担数据与集成。姓名待定，每人应能解释整体链路并交叉检查另一部分；AI 工具不计入大纲要求的小组人数。研究判断与教师沟通由学生承担。
