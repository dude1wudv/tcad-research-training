# 最简建模与辐照方法

本训练已经运行的模型入口是[geometry.scm](model/geometry.scm)与[build_case.py](build_case.py)。具体参数、单位及冻结边界统一见[plan.md](plan.md)，不再维护第二套参数表。文献阅读范围及原文链接见[literature.md](literature.md)。

## 1. 先证明它是 VDMOS，而不是画一张结构示意图

1. 二维 N 沟道平面栅对称半胞：顶部 N+ source 与 P+ body 共源接触，P-body 向 N- 漂移区扩散，底部 N+ drain；栅通过氧化层控制 body 表面的横向沟道。
2. P-body 与 N+ source 分别采用不同深度、横向扩散的高斯掺杂。不要把整个 body 表面设成 N+，否则可能失去实际沟道。
3. 使用真实 SDE 网格的净掺杂图和表面/深度切线核对符号与结位置。`DopingConcentration>0` 为净施主，负值为净受主；不同曲线必须注明切线坐标。
4. 先运行未加增量剂量的基线，核对 ID–VG 是否从关断进入导通、接触偏置和电流守恒，再冻结结构。R1 证明拓扑，不提供本训练的完整制造参数；本次数值是训练假设。

## 2. 剂量不能直接当作陷阱浓度

- 先确定吸收介质。本次为 `krad(SiO2)`，不能与论文的 `Gy(Si)` 无条件互换。
- R2 给出氧化物电子–空穴对生成关系。将剂量、氧厚、有效电荷产额与俘获比例相乘，得到面电荷增量；有效产额和俘获比例必须说明是测得、拟合还是假设。本次是未校准的假设。
- 正氧化电荷用 Silicon/Oxide 接口 `FixedCharge` 等效近界面电荷，**没有**解析整个氧化层体陷阱空间分布。
- 界面态另用可充放电的 donor/acceptor。下半带 donor、上半带 acceptor 的机制来自 R2；本次用两个离散 Level 近似，浓度单位是 `cm^-2`，不是连续态密度的 `cm^-2 eV^-1`。
- 由稳态解计算占据，不把所有界面态强制设成满占据。仅能声称等效“辐照后电学”计算，不能声称模拟了真实辐照、剂量率、退火或瞬态俘获。
- 不添加无来源硅体深能级来冒充总电离剂量；TID、位移损伤、单粒子效应分开处理。

## 3. 提取量必须与实际偏置、单位绑定

- ID–VG：固定器件内部 VDS，横轴用外加 `gate OuterVoltage`；`Barrier=-0.55` 对内部势有偏移，不能把 `gate InnerVoltage` 直接当外加 VGS。
- Vth：按冻结的定电流判据，保存实际相邻样本括区，仅对标量提取做对数电流插值；导出的逐点 CSV 不加入插值伪造的求解点。
- BV：用完整载流子雪崩与外接电阻追踪。提取用 `drain InnerVoltage`；`OuterVoltage` 包含串联电阻压降，不能当器件耐压。
- 电流判据 BV 与“雪崩主导”是两回事。用真实半导体冲击电离积分乘 `q*1e-12` 换算生成电流，与同点端电流比较；换算依据为安装版 `BVmethods/BV_SV_vis.tcl`，适用本次长度单位 µm、二维单位深度与 AreaFactor=1。更改归一化后须重新核实。
- 全域电场色标可能包括氧化层；判断硅雪崩时使用 `MaxSemiconductor ElectricField` 及其位置，不能把氧化层尖角峰值当硅击穿场。

## 4. 先判断数值可信度，再讨论辐照趋势

保持结构、掺杂、温度和模型一致，仅改变剂量对应的有效缺陷。检查工具退出码、完成标志、实际终点、有限数据、守恒和安全停止原因；至少对剂量端点做更细网格/更小步长复验，未通过就保留失败证据并明确数值限制。

正氧化电荷倾向使 NMOS 阈值负移，界面态可以抵消或改变该趋势；不能为了贴近某论文曲线而同步修改沟道长度、掺杂和功函数。本模型不含芯片终端、封装、自热、完整辐照散射或实验校准，不能由半胞 BV 推出整芯片额定耐压或真实抗辐照等级。
